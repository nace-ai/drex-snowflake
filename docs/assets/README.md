## Integration branding

The README uses **Drex for Snowflake**, with Nace artwork only and a descriptive reference to Snowflake.
Snowflake's [Partner Content Guidelines](https://www.snowflake.com/wp-content/uploads/2021/07/Partner-Content-Guidelines.pdf)
recommend the “Product/Service for Snowflake” form (pages 5 and 12) and discourage derivative
“snow” names. That document is dated May 2020 and applies to partners: it supports the wording,
but does not establish Nace's partner status or grant this integration a logo license.

Do not restore a combined logo header solely because Snowflake artwork is downloadable.
Consult the [brand guidelines](https://www.snowflake.com/brand-guidelines/) and any applicable
permission before adding provider artwork. This repository does not claim partnership or endorsement.

Snowflake is a trademark of Snowflake Inc.
